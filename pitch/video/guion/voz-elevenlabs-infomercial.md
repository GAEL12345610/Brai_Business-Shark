# Voz para ElevenLabs: guion del infomercial

Se genera **un audio por bloque**, nunca todo de corrido: así cada frase cae en su escena.

1. Copia el texto de un bloque, tal cual, y genera el audio.
2. Guárdalo con el nombre que dice el bloque dentro de `pitch/video/fuente/audio/infomercial/`.
3. Usa la misma voz y los mismos ajustes en todos los bloques.

Los números van escritos con letra a propósito, para que la voz los diga bien. No los cambies a cifras.

## Bloque 02 · guardar como `i02-el-artista.mp3`

```
Un artista pinta un cuadro durante meses. Lo vende. Y nunca vuelve a saber de él.
```

## Bloque 03 · guardar como `i03-las-dudas.mp3`

```
¿Es original? ¿Dónde está? ¿Cuál es su historia? Nadie lo sabe.
```

## Bloque 04 · guardar como `i04-brai.mp3`

```
Por eso creamos Brai. Un sello detrás de cada obra.
```

## Bloque 05 · guardar como `i05-el-toque.mp3`

```
Acercas tu celular, y la obra te cuenta su historia. Sin descargar nada.
```

## Bloque 06 · guardar como `i06-registrada.mp3`

```
Ves quién la pintó, y que la registró el propio artista. Si es tuya, la reclamas con tu tarjeta firmada.
```

## Bloque 07 · guardar como `i07-el-artista-sabe.mp3`

```
Así, quien la pintó sabe quién la reclamó.
```

## Bloque 08 · guardar como `i08-cualquier-celular.mp3`

```
Con NFC, con QR o con un código. Funciona en cualquier celular.
```

## Bloque 09 · guardar como `i09-cierre.mp3`

