# Voz para ElevenLabs: guion del video completo

Se genera **un audio por bloque**, nunca todo de corrido: así cada frase cae en su escena.

1. Copia el texto de un bloque, tal cual, y genera el audio.
2. Guárdalo con el nombre que dice el bloque dentro de `pitch/video/fuente/audio/completo/`.
3. Usa la misma voz y los mismos ajustes en todos los bloques.

Los números van escritos con letra a propósito, para que la voz los diga bien. No los cambies a cifras.

## Bloque 01 · guardar como `c01-portada.mp3`

```
Somos Brai. Cada obra sabe de dónde viene.
```

## Bloque 02 · guardar como `c02-problema.mp3`

```
Creemos que cuando una obra se vende, empiezan tres dudas. ¿Es original? Nadie lo sabe. ¿Dónde está? El artista pierde el rastro. ¿Y su historia? Jamás se cuenta.
```

## Bloque 03 · guardar como `c03-solucion.mp3`

```
Nuestra idea es simple. Un toque con el celular, y la obra te cuenta toda su historia. Sin descargar nada.
```

## Bloque 04 · guardar como `c04-pasos.mp3`

```
Funciona en cuatro pasos. El artista registra su obra con fotos e historia. Le ponemos un sello detrás. La entrega con una tarjeta firmada. Y quien la compra la reclama y queda como su dueño.
```

## Bloque 05 · guardar como `c05-sistema.mp3`

```
Por dentro, el sello abre una página, la página lee el registro, y el artista ve en su panel quién reclamó cada obra. Si tu celular no tiene NFC, también funciona con QR o con un código.
```

## Bloque 06 · guardar como `c06-demo.mp3`

```
Ya lo pueden probar. Escaneen el código y abran una obra de ejemplo.
```

## Bloque 07 · guardar como `c07-innovacion.mp3`

```
Lo diseñamos para que se vea, no para explicarlo. En cada página manda el artista, con su nombre y su color. Y solo decimos lo que sí hace: registrada por el artista.
```

## Bloque 08 · guardar como `c08-costo.mp3`

```
Ahora los números. Registrar una obra nos cuesta ocho pesos con setenta y tres centavos. El sello ya lo compramos. Lo demás es un estimado.
```

## Bloque 09 · guardar como `c09-costos-fijos.mp3`

```
Hoy, como prototipo, casi no gastamos: cuarenta y nueve pesos al año. Con clientes de verdad, serían unos ochocientos ochenta pesos al mes.
```

## Bloque 10 · guardar como `c10-precios.mp3`

```
Estamos probando dos precios. Uno con mensualidad: siete mil quinientos de arranque y novecientos noventa al mes. Otro por obra: dos mil quinientos de arranque y cuatrocientos cincuenta por cada obra. Todavía nadie ha pagado. Las entrevistas van a decidir.
```

## Bloque 11 · guardar como `c11-margen.mp3`

```
Por cada obra cobraríamos cuatrocientos cincuenta pesos, y los materiales nos cuestan menos de nueve.
```

## Bloque 12 · guardar como `c12-ganancia.mp3`

```
Es una proyección. Si llegamos a quince artistas, en un año ganaríamos doscientos setenta y ocho mil pesos con el primer precio, o cincuenta y nueve mil con el segundo.
```

## Bloque 13 · guardar como `c13-mercado.mp3`

```
En Jalisco hay ocho mil ochocientos setenta artistas visuales. Si dos de cada cien fueran clientes, serían ciento setenta y siete. Es una suposición nuestra, todavía sin validar.
```

## Bloque 14 · guardar como `c14-competencia.mp3`

```
Ya existen certificados digitales, y algunos son gratis. Lo nuestro es distinto: lo hacemos en persona, en español, y el comprador se registra solo.
```

## Bloque 15 · guardar como `c15-cierre.mp3`
